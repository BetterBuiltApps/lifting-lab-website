Rationale, Hero (two equal visuals)

Headline spans full width; visuals sit as a matched pair below it, no toggle, no primary/secondary sizing.

  • A toggle or tab would force a default state, and any default reads as "the real one", the brief is explicit that neither asset is secondary. A tab was rejected for that reason.
  • Instead the headline/CTA block moves above both shots, full width, so it doesn't have to be paired with just one of them. Below it, two equal-width device frames sit side by side, same size, same bezel treatment, visually identical weight.
  • Each gets a one-line caption naming what it does, since the two assets are different features (adaptive session builder vs. bar trace) and a viewer needs the words to read them as two products of the same coach, not one screenshot and a decorative second one.
  • Only the Bar Trace shot keeps the soft amber glow, dropped from the check-in shot so the glow doesn't quietly re-establish a hierarchy the layout is trying to avoid. If that reads as favoring Bar Trace, the glow can be cut entirely.

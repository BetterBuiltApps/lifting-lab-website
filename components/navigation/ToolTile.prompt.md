The Tools tab's grid tile. Amber glyph top, name and caption bottom, reserving two caption lines so the grid is even.

```jsx
<ToolTile title="Barbell Loader" subtitle="Plate diagram" icon="dumbbell" onClick={open} />
```

Captions are 2–4 words describing the output, not the action ("Loads off a PR", "Vs. world record"). Presses spring to 0.93.

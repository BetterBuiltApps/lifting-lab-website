Wraps content in the standard Lifting Lab card: `#232323`, 16px continuous corners, 16px padding, no border, no shadow.

```jsx
<Card><SectionLabel>Lift phases</SectionLabel>…</Card>
<Card padding={14} radius="row">…</Card>
```

Use `radius="row"` for list rows and the analysis/phase cards, which are 12px in the app. Cards never carry a border or a colored left edge.
